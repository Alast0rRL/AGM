# Changelog

## 2026-07-25

### Added
- **`state.asked_russian`**: новый флаг `ChatState`, после получения имени бот спрашивает «русская?» (в Stage 2 и Stage 3 phase 2).
- **`LOOKING_FOR_PATTERNS`**: новый список паттернов `["что ищешь", "кого ищешь"]` с ответом «тебя конечно» в обеих фазах Stage 3.
- **`RUSSIAN_CONFIRM_PATTERNS`**: новый список паттернов для подтверждения «русская?». Если после вопроса «русская?» партнёрша отвечает «да», «ага», «конечно» и т.п. — бот отвечает «ура».
- **Тесты** (`test_bot.py`): 244 теста (было 140). Добавлены секции:
  - `FROM_ASK_PATTERNS`, `NICE_TO_MEET_PATTERNS`, `WHAT_ARE_YOU_DOING_PATTERNS`, `HOW_ARE_YOU_PATTERNS`, `COMPLIMENT_PATTERNS`, `LOOKING_FOR_PATTERNS` — полное покрытие всех паттерн-листов
  - `AND_YOU_PATTERNS` / `NAME_ASK_PATTERNS` — ложные срабатывания после фикса паттернов
  - Дополнительные граничные случаи для `is_age_question`, `is_self_introduction`, `is_underage`, `is_dismissive`, `_partner_name_received`, `_already_sent_19`, `check_filters`

### Fixed
- **`AND_YOU_PATTERNS`**: убран standalone `"тебе"` (без знака вопроса). «Я тебе напишу» больше не ловится как встречный вопрос. `"а тебе"`, `"тебе?"` и другие варианты сохранены.
- **`NAME_ASK_PATTERNS`**: `"имя"` (standalone) заменён на `"имя?"` — «красивое имя» больше не срабатывает как вопрос имени. `"имя?"`, `"твое имя"`, `"как тебя зовут"` работают как раньше.
- **`UNDERAGE_PATTERNS`**: убраны «мне 17» и «мне семнадцать» — 17 входит в целевые возраста [17,18,19]. Из-за этого `check_filters("Мне 17")` завершал чат до проверки возраста.
- **Stage 2** (`stage_names:1074`): при таймауте ожидания (10с) бот теперь проверяет `state.said_19`. Если мы уже ответили «19» на «а тебе?», но собеседница не инициировала обмен именами — бот проактивно отправляет «Максим, тебя?» вместо скипа в Stage 3.
- **`is_underage`** (`bot.py:1434`): изменён regex поиска ведущего числа с `r'^(\d+)'` на `r'^(\d{2,})'`. Исправляет ложное срабатывание на фразы типа «7 лучше».
- **Stage 2** (`stage_names`): добавлено распознавание «я {имя}» (например «Я катя» → имя «катя»).
- **Stage 2 follow-up**: добавлены обработчики `FROM_ASK_PATTERNS` (→ «Уже в гости собралась») и `RUSSIAN_CONFIRM_PATTERNS` (→ «ура»).
- **`start_new_chat`**: если найден активный чат с сообщениями — форсируется новый чат (чтобы не залипали старые сообщения при перезапуске цикла).
- **`_NOT_NAMES`**: добавлен «ростов» — город больше не сохраняется как имя.
- **`is_muslim`**: вопросы про мусульман («А что с мусульманками не так?») больше не триггерят чат-стоп. Требуется `\bя\b` (самоидентификация) для срабатывания в вопросах.
- **`TG_CONTINUE_PATTERNS`**: новый список паттернов для предложений продолжить в Telegram. Ответ: «давай, скинь ссылку».
- **Тесты**: 270 тестов (было 255). Добавлены тесты для `is_muslim` (вопросы), `TG_CONTINUE_PATTERNS`, `_partner_name_received` (ростов, я катя).
- **Stage 2** (`stage_names:1074`): при таймауте ожидания (10с) бот теперь проверяет `state.said_19`. Если мы уже ответили «19» на «а тебе?», но собеседница не инициировала обмен именами — бот проактивно отправляет «Максим, тебя?» вместо скипа в Stage 3. Раньше после «19» бот молча ждал 10с → таймаут → Stage 3, а собеседница тоже ждала.
- **`is_underage`** (`bot.py:1434`): изменён regex поиска ведущего числа с `r'^(\d+)'` на `r'^(\d{2,})'`. Исправляет ложное срабатывание на фразы типа «7 лучше» (число 7 в начале — не возраст, а контекстное упоминание). Возраст уже проверен в Stage 1, повторная проверка на однозначные числа не нужна.

### Changed
- **Stage 2** (`stage_names`): убрана проактивная отправка «Максим, тебя?» после таймаута. Теперь бот ждёт в Stage 2 до 10с после последнего сообщения. Если собеседник не спрашивает «а тебе?» / не представляется / не спрашивает имя — переход в Stage 3. Если спрашивает возраст — ответ «19» и сброс таймера ещё на 10с.
- **Stage 1** (`stage_greeting`): убран лишний 25-секундный ожидание в `else` после ответа без возраста. Если собеседник не дал возраст, не спросил имя и не задал других распознаваемых вопросов — чат завершается сразу, без ожидания 5+20 секунд.
- **DISMISSIVE_PATTERNS**: добавлено «многа» для раннего обнаружения уклончивого ответа на «сколько лет».
- **Stage 3** (`stage_free_chat`): `name_asked` теперь определяется через `_name_already_sent(messages)`, а не `state.name_sent`. Исправляет баг, когда Stage 2 при таймауте выставлял `state.name_sent = True`, и Stage 3 проактивно отправлял «Максим, тебя?».
- **`wait_for_partner_msg`**: self-сообщения (введённые вручную) теперь добавляются в `messages` с `role='self'` вместо потери.
- **`_already_sent_19`**: теперь проверяет и `role='own'`, и `role='self'` — если пользователь вручную написал «19», бот не дублирует.

## 2026-07-24

### Fixed
- **Stage 2** (`stage_names`): bot теперь отвечает «Максим, тебя?» когда собеседник спрашивает «как зовут?». Ранее флаг `_partner_chatting` блокировал отправку имени, если собеседник уже написал что-то не-возрастное. Добавлен флаг `_name_q_received`.
- **Stage 3** (`stage_free_chat`): бот теперь распознаёт односложные имена (например «сабина») в ответ на «Максим, тебя?» и сохраняет их в `state.partner_name`. Добавлена ветка `is_single_name` в фазе 1 и фазе 2.
- **Stage 1** (`stage_greeting`): бот теперь отвечает «19» когда партнёр даёт возраст с «а тебе»/«тебе» (например «17 тебе»). Ранее detecting `age_text_has_and_you` ничего не делал, и бот переходил в Stage 2 не ответив свой возраст.
- **`wait_for_partner_msg`**: ускорено обнаружение завершения чата — проверка каждые 2 сек (было 5) с подтверждением за 1 сек (было 3). Вместо ~8 сек теперь ~3 сек. Убрана мгновенная проверка `_chat_alive` при входе (вызывала ложные None).
- **`is_self_introduction`**: добавлено распознавание формата «Имя Возраст» без «я» (например «Нина 19», «Света 18»). Ранее `is_self_introduction('Нина 19')` возвращала False → бот не отвечал «Максим 19» в Stage 1, а спрашивал «Максим, тебя?» в Stage 2.
- **TTS toggle**: добавлена плавающая панель 🔊/🔇 в правом верхнем углу страницы. Позволяет включить или выключить озвучку без перезапуска бота. Инжектится `page.evaluate()` после готовности страницы + MutationObserver для автоматического восстановления при пересоздании DOM.
